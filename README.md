# Furfolio · 云端发布 Beta 0.5.0

Vue 3 + Vite + TypeScript + Tailwind CSS + Pinia + Vue Router + GSAP。

仓库包含网站源码、自托管字体与示例素材、`outputs/cloud-setup/` 数据库迁移及独立的 `video/` 宣传片工程。本地密钥、依赖、构建产物、验收截图及导出视频不提交到 Git。下文其他 `outputs/` 路径是本地交付记录，不包含在源码仓库中。

四种风格、中文与英文名字独立字体控制已完成。线上地址：https://furfolio.pages.dev/ 。Phase 3 已接入用户名与密码注册、恢复码、登录后接续设计、Cloudinary 图片上传、云端草稿、发布链接及管理后台。负责人已执行 001～005 脚本，线上数据库控制版本为 4；真实 Supabase / Cloudinary 联调通过。

## 本地运行

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/ 。构建检查：`npm run build`。构建预览：`npm run preview`，端口 4173。

`npm run dev` 仅运行前端，本地没有生产 Secret，不能直接进行真实账号或云端操作。完整流程请在已部署的网站体验；本地 Functions 需单独运行 Wrangler Pages Dev 并配置被忽略的 `.dev.vars`，不要把生产 Secret 写入前端环境变量。

## 可以体验

- `/`：平台首页；`/templates`：四种风格的参考图、实际网页预览与编辑入口。
- `/preview?sample=1&template=y2k|minimal|cyber|editorial`：四种示例主页，切换风格与静态 / 轻盈 / 沉浸动效。
- `/editor`：主题、Hero、About、Likes、Gallery、Contact、排版与动效，七步编辑。
- `/preview`：自己的草稿，和编辑器共用渲染器。
- 发布前图片只在本地，支持透明立绘 / 普通照片、画廊与大图查看；点击云端保存或发布后才上传。
- `/login`：用户名与密码注册、登录、一次性恢复码找回；不填写邮箱，不需要 SMTP。
- 只有提交注册时加载并执行 Cloudflare Turnstile，服务端验证令牌、当前域名和注册 action 后才创建账号；选择风格、本地图片、编辑、预览、登录和已登录发布不要求验证。验证取消或失败保留设计，重试生成新令牌。
- `/dashboard`：载入云端草稿继续编辑、查看公开主页、撤下发布及重新生成恢复码。
- `/showcase`：首页底部按钮进入后才加载作品广场；仅显示已发布主页的名字和配色，每页 24 项，点击卡片打开专属主页。发布默认允许展示，后台可随时关闭，专属链接继续可访问。
- 已发布主页可在发布结果或后台生成带专用 logo 的二维码并下载 PNG，编码器与 logo 仅打开生成器时加载。
- `/u/:slug`：公开发布快照；保存新草稿不会改变访客看到的上一版。
- 栏目显示、顺序、桌面与手机分别保存的主图尺寸及偏移、间距、装饰与字体预设。
- 开场的设计栏内可拖动图片、缩放裁切、用方向键微调；原图保留，两种设备分别保存构图。
- 普通照片支持随原图比例、模板默认、竖幅、方形和横幅，以及完整显示 / 填满裁切；手机照片模式随文字高度排版。
- 关于栏目推荐独立头像：卡片左侧名字与可编辑短句、右侧固定方形头像。设计栏支持拖动、缩放、方向键裁剪和恢复默认，裁剪随本地与云端草稿保存，原图保留；已移除 About me 小字。
- 画廊按原图比例展示，不强制裁成竖图，缩略图也完整显示。手机大图按可用屏幕完整显示图片，适配安全区域，切换和关闭按钮保持可见；示例拼图的大图只显示所选一张。
- 每项喜好可添加一张点击后展示的详情图片。
- 云端图片统一通过本站 `/api/media/…` 获取实际图片内容，覆盖主图、头像、喜好详情、画廊、大图与编辑栏缩略图；旧主页及已有云端草稿自动兼容，无需重新上传或发布。
- 每个栏目展开“栏目文案与字体”，可修改装饰短句、栏目标题、空状态文案和引导文字；每段分别选 9 种字体之一，含中文字体，支持恢复模板。
- 手机采用独立响应式构图；编辑器 iframe 以真实 1120 / 390 px 宽度渲染。
- 四种模板共享资料与本地图片，每套有 8 组推荐配色，切换后记住各自配色及字体。
- 内容字体有现代、衬线、手写、圆润四种气质；中文名字与英文名字分别选择字体，主题与开场步骤均有入口。名字默认跟随模板，字体记忆随各自模板保存。
- 喜好条目可点击打开详情，编辑器支持一句说明、进一步介绍、详情图片及选填的 HTTP / HTTPS 相关链接。
- 联系方式可填写 HTTP / HTTPS 网址、QQ 号、用户名或邮箱。网址点击打开，其他文本点击复制并显示反馈；自动复制不可用时提供可选取的手动复制内容。本地与云端保留账号开头的零。
- 新草稿动效默认轻盈；已有草稿的明确选择会保留。系统减少动态设置优先。
- Y2K / Cyber 的开场文字带在轻盈与沉浸模式中缓慢无缝滚动，Cyber 背景线条细微漂移；离屏或后台暂停。各栏目、头像卡、画廊与喜好详情柔和展开，曲线平滑收尾；关闭动效时静态显示。

## 素材边界

`public/demo/` 的两张 AI 角色插画只供示例资料与首页展示，`public/references/` 是设计审阅图。它们不会进入新用户草稿，也不作为真实主页的兜底图片。正式模板不包含 AI 角色图或 AI 3D 图标。当前背景、纸边、网点与装饰由 CSS / SVG 滤镜绘制。

界面图标采用文字箭头与简单二维形状。Satoshi 字体自托管，来源为 Fontshare；新增字体来自 Google Fonts，WOFF2 与许可文件放在 public/assets/fonts/。按所选字体加载本地样式，中文使用 Unicode 子集按实际字符下载。Georgia 和默认楷体使用系统字体与回退。

## 数据与实现边界

- localStorage 的 `fursona:draft:v1` 只存轻量配置与稳定 assetId；IndexedDB `fursona-assets/images` 存 Blob。刷新重新生成 Object URL。
- 本地草稿绑定当前浏览器和访问来源；localhost 与正式域名不会自动共享。云端保存成功后，可以登录后台在其他设备载入。
- `src/domain` 定义并规范化资料，`stores` 管理编辑与账号状态，`persistence` 负责本地图片，`renderer` 统一渲染，`pages` 组织流程；`server` 负责认证与数据访问，`functions/api` 提供 Pages 路由。
- 登录前后保留同一个本地草稿。云端草稿与公开快照分开，发布事务核验版本和图片所有权。
- 密码与会话由 Supabase Auth 管理；登录 token 仅放在 Secure / HttpOnly / SameSite Cookie。浏览器不接触 Supabase Secret 或 Cloudinary API Secret。
- 图片先在浏览器压缩，再经受限的服务端上传接口：最多 3 MB、长边 2000 px。当前 Beta 每账号最多保存 24 张云端图片；旧图片的回收界面尚未实现，替换图片也会占用此额度。
- 图片转发只允许 Cloudinary `jcirypaz` 账户中 Furfolio 固定上传路径的 PNG / JPEG / WebP 原图，不接受外部网址、转换参数或上游跳转。浏览器缓存 1 天，边缘缓存 7 天；缓存按数据中心保存，命中仍调用 Functions。来源：[Cache API](https://developers.cloudflare.com/workers/runtime-apis/cache/)、[Pages Functions 计费](https://developers.cloudflare.com/pages/functions/pricing/)。
- 主图框内拖动裁切已实现。通用元素拖动、吸附、撤销 / 重做、Hero 多图轮播、按模板独立保存布局与草稿导出将在后续阶段实现。

## Cloudflare 部署准备

`npm run deploy:check` 检查当前 dist 文件数量和大小。`npm run deploy:pages -- --account-id <ID> --project <名称> --profile <独立登录配置> --branch main` 自动构建并部署；账户、项目与登录配置必须明确指定，不使用当前账户作为默认值。当前项目已绑定独立 OAuth profile `fursona-20261010`，目标项目为 `furfolio`。部署与用户名注册方案见 `outputs/deployment-plan.md`，线上核验记录见 `outputs/deployment-status.md`。
